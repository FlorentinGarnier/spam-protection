# Security Policy

## Supported versions

Only the latest released minor version receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/FlorentinGarnier/spam-protection/security/advisories/new). Include
the affected version, a description of the issue and, if possible, the steps to reproduce it.

You will receive an answer within a week. Once the issue is confirmed, a fix is prepared and released, then the
advisory is published with credit to the reporter, unless you prefer to remain anonymous.

A way to submit a form without solving the challenge, or to reuse a token, is a vulnerability. The limitations
listed in the README (visitors without JavaScript, IPv6 addresses, residential proxies) are not.
